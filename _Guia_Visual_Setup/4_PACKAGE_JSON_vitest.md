# ¿PARA QUÉ ES ESTO?
Son los paquetes y scripts de Vitest y Husky necesarios para tu agente de Testing TDD.

**DÓNDE VA:** Pega esto o instálalo en tu `package.json`

---

```json
{
  "scripts": {
    "test": "vitest",
    "prepare": "husky"
  },
  "devDependencies": {
    "husky": "^9.1.7",
    "vitest": "^4.1.8",
    "@testing-library/react": "^16.3.2",
    "jsdom": "^29.1.1"
  }
}
```
